# Laptop and Desktop Options — Full Score and Value Comparison

Prices are in Philippine pesos and include online delivery where applicable. The desktop option is scored with its included 25-inch 320 Hz monitor and peripherals, since it needs them to be usable.

## Important desktop adjustment

The **Legion Tower 5i** uses a desktop **RTX 5060 Ti 8 GB**, which performs substantially better than a laptop RTX 5060 and is broadly closer to a laptop RTX 5070-class GPU in gaming performance. For this comparison, it receives a GPU score of 8—equal to the laptop RTX 5070 tier—rather than the laptop RTX 5060 score of 5.

Its TGP field is not directly comparable because desktop graphics cards use a different power-limit system. For scoring consistency, the desktop GPU receives a performance-equivalent TGP contribution based on its RTX 5070-class gaming performance.

## Scoring criteria

\[
\text{Score} =
(2 \times \text{GPU tier})
+ \frac{\text{VRAM}}{2}
+ \frac{\text{TGP or desktop GPU performance equivalent}}{20}
+ \frac{\text{RAM}}{8}
+ \frac{\text{Storage}}{512}
+ \frac{\text{CPU tier}}{2}
+ \frac{\text{Freebies}}{3}
+ \text{Warranty years}
\]

| Component | Scoring rule | Maximum contribution |
|---|---|---:|
| GPU tier | Laptop RTX 5050 = 3, RTX 5060 = 5, RTX 5070 = 8; desktop RTX 5060 Ti = 8; multiplied by 2 | 16 |
| VRAM | VRAM in GB divided by 2 | 8 for 16 GB |
| GPU power / performance | Laptop TGP divided by 20; desktop RTX 5060 Ti uses an 8/20 performance-equivalent score | 7 |
| RAM | RAM in GB divided by 8 | 12 for 96 GB |
| Storage | Storage in GB divided by 512 | 4 for 2 TB |
| CPU class | Manual CPU tier score divided by 2 | 5 |
| Freebies / bundle | Manual bundle score divided by 3 | 10 for the full Lenovo bundle |
| Warranty | 1 point per year | 2 for two years |

\[
\text{Value score} =
\frac{\text{Score}}{\text{Price} / 100{,}000}
\]

A higher Value score means more specification value per ₱100,000. This is a specification-value metric, not a benchmark; model-specific reliability and thermal concerns are handled in the final adjusted ranking.
